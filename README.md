# Website profissional — Cláudio Corrêa

Home Page independente da TNA, desenvolvida em HTML5, CSS3 e JavaScript.

## Estrutura

- `index.html` — estrutura e conteúdo.
- `css/style.css` — identidade visual e responsividade.
- `js/main.js` — navegação móvel e ano automático.
- `assets/images/` — imagens adicionais.
- `assets/icons/` — ícones adicionais.

## Teste local

Na pasta do projeto, executar `python3 -m http.server 8000` e abrir `http://localhost:8000`.

## Antes da publicação

1. Substituir `INSERIR_EMAIL` em `index.html` pelo email profissional.
2. Rever os textos das secções Projetos e Publicações.
3. Testar a navegação em computador e telemóvel.
4. Enviar primeiro para a branch `novo-perfil-profissional`.
5. Não alterar a branch `main` nem as definições atuais do GitHub Pages até à validação final.
